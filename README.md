Simon Says Game:-

An interactive memory‑based game built using **JavaScript, HTML, and CSS**.  
Players must repeat increasingly complex sequences of colors and sounds to progress.

Features:
- Random sequence generation
- Event handling for user clicks
- Game state management (levels, restart)
- Engaging UI with colors and sounds

Tech Stack:
- HTML
- CSS
- JavaScript (DOM manipulation)

Project Structure:
index.html → Game interface
style.css  → Styling and layout
script.js  → Game logic and event handling

How to Play:
1. Clone this repository:
   ```bash
   git clone https://github.com/Gopal230/Simon-Says-Game.git
2. Open index.html in any browser
3. Click any button to start --> Follow the sequence to advance levels.
